# Palabras reservadas de FitLang

| Palabra reservada | Significado | Categoría |
|---|---|---|
| `rutina` | Define el bloque que agrupa una rutina de entrenamiento | Palabra clave |
| `ejercicio` | Define el bloque de un ejercicio dentro de una rutina | Palabra clave |
| `series` | Indica el número de series de un ejercicio | Palabra clave |
| `repeticiones` | Indica el número de repeticiones de un ejercicio | Palabra clave |
| `peso` | Indica el peso utilizado en un ejercicio | Palabra clave |
| `descanso` | Indica el tiempo de descanso entre series (en segundos) | Palabra clave |
| `objetivo` | Define el objetivo de entrenamiento (fuerza, hipertrofia, resistencia) | Palabra clave |
| `activo` | Indica si un ejercicio está activo o no | Palabra clave |
| `si` | Inicia una estructura condicional | Palabra clave / estructura de control |
| `sino` | Define la alternativa de una estructura condicional | Palabra clave / estructura de control |
| `y` | Operador lógico de conjunción (AND) | Operador lógico |
| `o` | Operador lógico de disyunción (OR) | Operador lógico |
| `>` | Mayor que | Operador relacional |
| `<` | Menor que | Operador relacional |
| `>=` | Mayor o igual que | Operador relacional |
| `<=` | Menor o igual que | Operador relacional |
| `==` | Igual a | Operador relacional |
| `verdadero` | Valor booleano verdadero | Literal |
| `falso` | Valor booleano falso | Literal |

## Acciones reconocidas (no son palabras reservadas, pero son funciones válidas dentro de un bloque `si`)
`aumentar_peso`, `reducir_peso`, `mantener_peso`, `aumentar_series`, `aumentar_descanso`, `reducir_descanso`, `pausar_rutina`
